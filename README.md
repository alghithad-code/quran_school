# نظام إدارة مدرسة تحفيظ القرآن — النسخة الكاملة (v1.0)

Node.js + Express + MongoDB Atlas + React (PWA) — عربي RTL للجوال، ويعمل أونلاين فقط.

## ما يشمله
- **الحسابات والصلاحيات:** مدير نظام / مشرف / معلم. العزل مفروض في الخادم: المعلم لا يرى إلا طلابه الحاليين ولا يعدّل إلا سجلاته.
- **الطلاب:** إضافة وتعديل وأرشفة (دون حذف السجلات)، جدول حضور (أيام ووقت الحضور وبداية/نهاية التسميع)، قائمة اليوم مرتبة بالمواعيد.
- **النقل:** طالب أو عدة طلاب دفعة واحدة داخل Transaction، مع مراجعة قبل التأكيد وإشعار للمعلمين.
- **التسجيل اليومي:** حضور وغياب (سجل واحد لكل طالب يومياً)، الحفظ والمراجعة بتقييم مستقل لكل مقطع (بالسورة والآيات مع التحقق من الأعداد، أو بالصفحات)، وملاحظات مصنفة.
- **المستويات:** إنشاء وترتيب وربط المعلمين، وطلب ترقية من المعلم بملخص آخر 30 يوماً، وقرار المشرف، وخفض بسبب إلزامي.
- **الإشعارات:** طالب جديد، نقل، ترقية/خفض، طلب ترقية، غياب متكرر.
- **اللوحات:** مدير/مشرف ومعلم، والبطاقات تفتح القائمة المفلترة نفسها.
- **التقارير:** طالب / معلم / مدرسة بفلاتر الشهر والمعلم والمستوى، مع طباعة (PDF من المتصفح) وتصدير Excel.
- **سجل العمليات:** للقراءة فقط مع القيم السابقة والجديدة، وتنظيف تلقائي بحسب مدة الاحتفاظ.
- **النسخ الاحتياطي:** تلقائي أسبوعي، يدوي، تنزيل، رفع نسخة خارجية، استعادة بتأكيد صريح مع نسخة أمان وتراجع تلقائي عند الفشل.
- **PWA:** يُثبَّت على الجوال. لا يُخزَّن أي طلب بيانات مؤقتاً.

## الطالب والتسجيل في المستويات (v2.0)
- **الطالب** = الشخص (الاسم والعمر والهاتف). **التسجيل** = التحاقه بمستوى: لكل تسجيل معلمه وجدوله وموضع حفظه وحضوره وتقييماته وملاحظاته وشريط تقدّمه وطلب ترقيته.
- قد يُسجَّل الطالب في عدة مستويات بمعلمين مختلفين. النقل والترقية والحضور تتم لكل تسجيل على حدة.
- المعلم يرى تسجيلاته فقط (ومنها الطلاب الذين يراهم)، فلا يطّلع على بقية مستويات الطالب عند غيره.
- عند أول تشغيل بعد التحديث يُرحَّل تلقائياً أي طلاب قدامى إلى تسجيلات (آمن للتكرار)، ويُحذف فهرس الحضور القديم.
- النسخ الاحتياطية القديمة (قبل v2.0) لا تصلح للاستعادة بعد التحديث، فخذ نسخة جديدة.

## التشغيل محلياً
1. `cp .env.example .env` وعبّئ القيم. (**اجعل MONGODB_URI يشير إلى قاعدة خاصة بهذا النظام، مثل quran_school.**)
2. `npm install && npm run build && npm start` ثم افتح http://localhost:3000

## النشر على Render
`render.yaml` جاهز. القيم السرية تُضاف في Render فقط. بعد أول تشغيل احذف `INITIAL_ADMIN_PASSWORD`.

## ملاحظات تشغيلية مهمة
- **MongoDB:** النقل والترقية يستخدمان Transactions، وهي متاحة في Atlas (حتى المجاني). لا تستخدم MongoDB منفرداً بلا Replica Set.
- **الخطة المجانية في Render تنام** بعد فترة خمول، وقد تفوت النسخة التلقائية الأسبوعية. نزّل نسخة يدوية دورياً واحفظها خارج الاستضافة.
- **النسخة تحتوي** بيانات المدرسة وتجزئات كلمات المرور (لا أسرار اتصال). تعامل معها كملف سري.
- كلمة سر قاعدة البيانات لا تُرفع إلى GitHub أبداً.

## اختبار القبول المقترح
1. أنشئ مستويين ومعلمين ومشرفاً. 2. أضف طلاباً وحدد جداولهم. 3. سجّل حضوراً وحفظاً ومراجعة بتقييمات مختلفة بحساب المعلم. 4. جرّب أن معلماً آخر لا يرى هؤلاء الطلاب. 5. انقل طالباً ثم عدة طلاب وتحقق من الإشعارات وبقاء السجلات القديمة. 6. ارفع طلب ترقية ووافق عليه. 7. اخفض مستوى طالب بسبب. 8. سجّل غياباً متتالياً حتى يصل التنبيه. 9. افتح التقارير الثلاثة وصدّر Excel واطبع. 10. أنشئ نسخة ونزّلها ثم جرّب الاستعادة على بيانات تجريبية.
